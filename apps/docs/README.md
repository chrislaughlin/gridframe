# Gridframe docs app

The public documentation site for Gridframe. The current landing page covers
AI-generated Dashboard proposals, supported providers, the proposal lifecycle,
integration, routes, and security boundaries.

Run it from the repository root:

```sh
pnpm --filter docs dev
```

Open [http://localhost:3001](http://localhost:3001).

The detailed source documentation lives in
[`docs/ai-dashboards.md`](../../docs/ai-dashboards.md). Keep the site and that
guide aligned when the AI contract changes.
